## 1. Описание проекта

Проект решает задачу линейного программирования: минимизировать стоимость смеси из восьми компонентов при выполнении минимальных требований по белку, энергии, клетчатке, кальцию и фосфору.

Данные синтетические. Для воспроизводимости генератор использует `seed = 10213`.

В модели дополнительно задано ограничение на общую массу смеси:

$$
\sum_j x_j = 9 \text{ кг}.
$$

## 2. Структура проекта


```

├── data/
│   ├── products.csv          # цены и нутриенты компонентов
│   └── requirements.csv      # минимальные требования
├── generate_data.py          # генерация данных (seed=10213)
├── model.py                  # базовая модель + независимая проверка
├── scenario_analysis.py      # сценарии +20% / +40% и теневые цены
├── stress_analysis.py        # диагностика infeasible
├── requirements.txt          # зависимости
├── README.md
│
├── solution.csv              # оптимальный состав (после model.py)
├── independent_check.csv     # проверка ограничений
├── solver_log.txt            # лог HiGHS
├── scenario_results.csv      # сравнение 3 сценариев (стоимость, статус)
├── shadow_prices.csv         # теневые цены ограничений
├── stress_maximums.csv       # макс. достижимые значения нутриентов
├── stress_leave_one_out.csv  # допустимость при удалении 1 ограничения
└── stress_pair_check.csv     # допустимость при удалении пар ограничений
```



## 3. Зависимости

```bash
pip install -r requirements.txt

```
Используются: numpy, pandas, scipy (HiGHS), matplotlib.


## 4. Порядок зависимости

Команды выполняются из корня проекта.

1. Сгенерировать данные (создаёт data/):
```bash 
python generate_data.py
```
2. Решить базовую задачу, выполнить независимую проверку и сохранить лог:
```bash
python model.py
```
3. Сценарный анализ и теневые цены:
```bash
python scenario_analysis.py
```
4. (Опционально) Диагностика стрессового сценария:
```bash
python stress_analysis.py5. 
```


## 5.Результаты базового эксперимента
- Статус HiGHS: Optimal
- Минимальная стоимость: 152.066126 руб.

Независимая проверка (NumPy) подтвердила выполнение всех пяти ограничений (допуск 1e-7), неотрицательность переменных и массу 9 кг.
