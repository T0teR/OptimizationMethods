# Лабораторная работа № 2 — методы оптимизации

**Seed:** `10213`

## 1. Постановка

Сеть: 3 источника (S1–S3), 2 хаба (H1, H2), 5 потребителей (C1–C5).  
Дуги: все S→H, все H→C, плюс несколько прямых S→C.  
Цель: минимизировать суммарную стоимость перевозок при выполнении предложений, спросов, балансов хабов и ограничений пропускной способности.

## 2. Структура проекта

```
lab2/
├── data/
│   ├── nodes.csv              # узлы: тип, supply, demand
│   └── arcs.csv               # дуги: from, to, cost, capacity
├── generate_data.py           # генерация данных (seed=10213)
├── model.py                   # LP-модель + независимая проверка
├── visualize.py               # схема сети с потоками (NetworkX)
├── scenario_analysis.py       # сценарии + жадная эвристика + теневые цены
├── milp_integer.py            # целочисленные потоки LP vs MILP
├── dual_analysis.py           # двойственная интерпретация / потенциалы
├── requirements.txt           # зависимости Python
├── README.md                  # описание проекта и запуск
├── solution_flows.csv         # оптимальные потоки по дугам
├── independent_check.csv      # проверка балансов узлов
├── solver_log.txt             # лог HiGHS (базовый сценарий)
├── scenario_results.csv       # сравнение сценариев (стоимость, статус)
├── shadow_prices.csv          # теневые цены / потенциалы узлов
├── greedy_flows.csv           # потоки жадной эвристики
├── lp_vs_milp.csv             # сравнение LP-релаксации и MILP
├── reduced_costs.csv          # приведённые стоимости дуг
└── figures/network_flows.png  # визуализация сети с потоками
```

## 3. Запуск

```bash
pip install -r requirements.txt
python generate_data.py
python model.py
python visualize.py
python scenario_analysis.py
python milp_integer.py          
python dual_analysis.py         
```
